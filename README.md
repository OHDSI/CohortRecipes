# CohortRecipes

<!-- badges: start -->

<!-- badges: end -->

The goal of CohortRecipes is to standardise common cohort definitions in
OMOP CDM. You can use your own conceptSets or the ones defined in
OmopConcepts.

## Installation

You can install the development version of CohortRecipes like so:

``` r
# install.packages("pak")
pak::pkg_install("ohdsi/CohortRecipes")
```

Or from CRAN:

``` r
install.packages("CohortRecipes")
```
